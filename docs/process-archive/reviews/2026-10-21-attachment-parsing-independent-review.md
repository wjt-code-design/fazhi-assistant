## 2. 原报告三项结论的复核

### 2.1 A01：块级内容控件正文被静默丢弃 —— 成立

| 合成输入 | 本轮实测解析结果 | 判定 |
| --- | --- | --- |
| 普通段落“合同正文” + 普通段落“乙方不得提前解除合同。” | `合同正文\n乙方不得提前解除合同。`，warnings 为空 | 对照成立 |
| 普通段落 + `w:sdt`/`w:sdtContent` 内的同一句 | `合同正文`，warnings 为空 | **条款静默丢失，成立** |
| 仅 `w:sdt` 内的同一句 | 抛 `ValueError`：“提取文本为空（可能是扫描件或无文字内容）” | **全文控件被误判为扫描件，成立** |

机制确认：`extract()` 只遍历 `w:body` 的直接子节点，且只处理段落与表格两种标签；内容控件的正文位于 `w:sdtContent` 之下，不在直接子节点之列。

补充事实：**该缺陷只发生在正文层级的分派**。行内内容控件（`w:p` 内的 `w:sdt`）与表格单元格内的内容控件都会被 `iter()` 递归到，文本正常保留。因此修复时应修改块级分派，而不是给所有文本提取加特例。

### 2.2 A02：表格单元格内段落/换行/制表符被无分隔拼接 —— 成立

| 单元格内结构 | 普通正文对照 | 表格内实测 | 判定 |
| --- | --- | --- | --- |
| 两个段落 `1000`、`2000` | `1000\n2000` | `10002000` | **数字边界丢失，成立** |
| 两段之间 `w:br` | `1000\n2000` | `10002000` | 成立 |
| 两段之间 `w:tab` | `1000 2000` | `10002000` | 成立 |

三个表格输入均无 warnings、均成功返回，属于“解析成功但事实被改变”。机制确认：`_table_text()` 对单元格内所有 `w:t` 直接做空串拼接，没有复用 `_para_text()` 的换行/制表处理，也没有在段落之间插入分隔。

### 2.3 A03：两个 async 上传入口同步执行解析 —— 成立（未测耗时）

主仓当前代码形状：

- `chat_file()` 与 `admin_upload()` 均为 `async def`；
- 两者都在函数体内直接调用 `ks.parse_upload_or_raise(...)`，之后才把纯截断/入库工作放进 `run_in_threadpool`；
- PDF/DOCX 的实际解析发生在进入线程池之前。

判定：**“同步解析发生在事件循环中”这一调用位置结论成立**。原报告没有给出毫秒、吞吐或故障概率，本轮同样不给；需要延迟实验才能量化。

### 2.4 O01：DOCX warnings 被丢弃 —— 成立

`knowledge_service.parse_uploaded()` 把 `extract()` 的第二个返回值绑定为 `_warnings` 后不再使用；`/api/chat/file` 的响应字段只有文件名、扩展名、字符数、截断标志和文本，没有 warnings 契约。判定：数据流事实成立，属于待定契约，不是已发生的用户可见错误。

### 2.5 O02：删除会话不清理图片文件 —— 成立

- `delete_conversation()` 只删除会话记录并提交；`Conversation.messages` 为 `cascade="all, delete-orphan"`，消息行随之删除。
- 图片文件清理函数只用于失败请求的回滚，未接入成功会话的删除路径。
- `get_media()` 同时校验登录身份与 Message→Conversation 归属；会话删除后消息行不存在，原图/缩略图通常不能再通过该端点读取。

判定：**“磁盘残留 + 接口不可再读”成立**；不能据此声称图片会公开。保留期限、备份保留与回收策略仍无明确契约。

## 3. 新增发现

### N01（P2）：嵌套表格被重复提取

合成结构：外层表格的单元格内再放一张表格。

本轮实测输出：

```text
外层A内层B | 内层B
内层B
```

判定与后果：

- 内层文本“内层B”出现两次；
- 外层单元格把“外层A”和“内层B”直接拼成“外层A内层B”，没有段落或表格边界；
- 原因：`_table_text()` 用 `tbl.iter(tr)` 与 `tr.iter(tc)` 递归遍历，外层行会把嵌套行/单元格一并收进来，随后嵌套行又被单独输出一遍。

与 A02 的区别：A02 是单元格内部的边界丢失；N01 是**同一段正文被重复计入**。重复的金额或日期同样会改变模型看到的事实，且比丢失更难被用户察觉。

### N02（P2）：被跳过的块级容器不止内容控件

| 合成输入 | 本轮实测 | 判定 |
| --- | --- | --- |
| `w:sdt` 内放表格 | 抛“提取文本为空” | 与 A01 同源，表格也被整体丢弃 |
| `w:customXml` 包裹段落 | 抛“提取文本为空” | 同类块级容器同样被跳过（较低频，置信度中） |
| 表格单元格内的 `w:sdt` | `3000` 正常保留 | 说明缺陷在正文块分派，不在文本收集 |
| 行内 `w:sdt` | `5000` 正常保留 | 同上 |

因此 A01 的修复口径应写成：**正文层级的块分派需要能进入合法的块级容器并保持原顺序**；只给 `w:sdt` 打一个补丁，会留下 `w:customXml` 等同类缺口。

## 5. 复现方法与证据

本轮使用的独立脚本位于系统临时目录（不属于仓库交付物），核心逻辑如下；它只导入 `docx_utils`，不触碰产品服务：

```python
import io, sys, zipfile
sys.path.insert(0, r"c:\Users\33393\Desktop\ai-legal-helper\backend")
import docx_utils

NS = 'xmlns:w="http://schemas.openxmlformats.org/wordprocessingml/2006/main"'

def make_docx(body_inner: str) -> bytes:
    doc = f'<w:document {NS}><w:body>{body_inner}</w:body></w:document>'
    buf = io.BytesIO()
    with zipfile.ZipFile(buf, "w", zipfile.ZIP_DEFLATED) as z:
        z.writestr("word/document.xml", doc)
    return buf.getvalue()

def p(text):      return f"<w:p><w:r><w:t>{text}</w:t></w:r></w:p>"
def sdt(inner):   return f"<w:sdt><w:sdtContent>{inner}</w:sdtContent></w:sdt>"
def table(cell):  return f"<w:tbl><w:tr><w:tc>{cell}</w:tc></w:tr></w:tbl>"

cases = {
    "A01_plain":     p("合同正文") + p("乙方不得提前解除合同。"),
    "A01_sdt":       p("合同正文") + sdt(p("乙方不得提前解除合同。")),
    "A01_sdt_only":  sdt(p("乙方不得提前解除合同。")),
    "A02_two_paras": table(p("1000") + p("2000")),
    "A02_br":        table('<w:p><w:r><w:t>1000</w:t></w:r><w:br/><w:r><w:t>2000</w:t></w:r></w:p>'),
    "A02_tab":       table('<w:p><w:r><w:t>1000</w:t></w:r><w:tab/><w:r><w:t>2000</w:t></w:r></w:p>'),
}

for name, body in cases.items():
    try:
        text, warns = docx_utils.extract(make_docx(body), name + ".docx")
        print(name, repr(text), warns)
    except ValueError as e:
        print(name, "ValueError:", e)
```

| --- | --- |
| `A01_plain` | `合同正文\n乙方不得提前解除合同。` |
| `A01_sdt` | `合同正文` |
| `A01_sdt_only` | `ValueError: 提取文本为空（可能是扫描件或无文字内容）` |
| `A02_two_paras` / `A02_br` / `A02_tab` | 均为 `10002000` |
| 普通正文对照（两段落 / `w:br` / `w:tab`） | `1000\n2000` / `1000\n2000` / `1000 2000` |
| 嵌套表格 | `外层A内层B \| 内层B\n内层B` |
| `w:sdt` 内表格 / `w:customXml` 段落 | 均抛“提取文本为空” |
| 行内 `w:sdt` / 单元格内 `w:sdt` | `5000` / `3000` |

现有 `backend/tests/test_docx.py` 覆盖了直接段落、简单表格、删除修订、warnings 与非法 ZIP；其表格 fixture 每格只有一个简单段落，本轮未在其中找到内容控件、同格多段落/换行/制表符或嵌套表格的断言。这**不等于**全仓没有其他覆盖，只说明该文件不能证明这些形状已被守住。
