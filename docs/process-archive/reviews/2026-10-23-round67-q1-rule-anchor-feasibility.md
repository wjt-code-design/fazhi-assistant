## 1. 两个候选判据的精确定义

探针：`dispatch-output/round67-q1-20261023/probe_rule_anchor_feasibility.py`，输出 `probe-rule-anchor.out`。

**C1（最小规则锚，即方案 A 字面实现）**
1. 每条 claim 至少一个锚 `{evidence_id, quote}`；
2. `evidence_id ∈ claim.evidence_ids`；
3. `quote` 归一化（NFKC、去标点空白）后必须是该证据 `snippet` 的逐字子串，长度 ≥ 8；
4. claim 正文里的每个条号，都能在某个锚点的证据（`source_ref + snippet`）中找到。

**C2（封闭世界逐段覆盖）**
1. claim 按 `。；;！!？?，,` 切段；
2. 每段字符（虚词/连接词白名单除外）必须出现在「绑定证据（条号+法名全称+原文）+ 绑定事实 + 未决事实」里；
3. 含不确定性标记（尚需确认/待确认/无法确定/取决于/有待…）的段豁免。

C2 是 C1 的加强版：它不只校验“锚是真的”，还校验“整句话的内容都来自依据”。

## 3. 正常答案读数（C2 的误杀面）

| 样本 | 性质 | C2 |
|---|---|---|
| N1 根据《民法典》第一百八十八条，诉讼时效期间为三年。 | 逐字引条文 | PASS |
| N2 根据《民法典》第五百八十五条，**当事人可以约定违约金**。 | 逐字引条文（依据库 snippet 为节录） | **拦**：`事人当` |
| N3 根据《劳动合同法》第八十二条，公司未签书面合同应支付二倍工资。 | 条文+事实适用 | PASS |
| N4 **建议补充工资发放记录与考勤记录，以确认实际工资标准。** | 六段式必备的“可执行建议” | **拦**：`充勤发建录放考补议记`、`准实标确认际` |
| N5 公司超过一个月未与劳动者签订书面劳动合同，应当向劳动者每月支付二倍的工资。 | 条文转述 | PASS |
| N6 根据《劳动合同法》第八十二条，**劳动者有权要求**公司每月支付二倍工资。 | 条文转述 | **拦**：`权求要` |

- N4 是决定性的：产品六段式固定包含“可执行建议与风险提示”，建议语（补充材料、核对记录）**天然不可能逐字来自法条或事实**。C2 一旦上线，建议段只能被删或被拒 ⇒ 直接违反验收 #2。
- N2/N6 说明即使是被支持的转述，只要证据 snippet 是节录、或用了同义表述（有权要求），也会被整条拒绝。
- 加强 C2 的“不确定性豁免”也不能解决：豁免以段为单位，缺口句只要与“尚需确认”同段就会被一起放行（例如“仲裁时效尚需确认”会被豁免）；改按逗号切分又会把正常条件句切碎。

## 4. 归因（为什么这不是实现技巧问题）

- 要关闭 Q1，必须判断**没有条号的句子是否在断言法律规则**。
- 纯确定性手段只有两条路：
  - **词表**：用“时效/差额/基数/上限”等命中即要求依据 —— 报告 §5 已明确反对，换样本即失效；
  - **封闭世界覆盖**：要求整句字符都来自依据 —— 上面 N2/N4/N6 证明会误杀正常答案与必备建议段。
- 两条都被验收 #2 或既有决议排除。**这不是阈值/调参能补的，属于判据能力边界。**

## 5. 建议（需 Owner 决策，二选一）

1. **（推荐）B：离线独立支持审查器**，先只进评测、不进线上阻断。证据封闭，输出 `{supported, unsupported_spans}`，用一红一绿 + 稳定性证据控制；与 A 不冲突，A 可作为它的确定性前置（锚是真的是必要条件）。
2. **A-lite：只把规则锚当“引用透明度契约”**（C1 + 提示词要求逐字展示条文），并**在验收口径中如实写明 Q1 仍未关闭**。它只关掉“伪造锚/条号无锚”，不关“外推规则”。

不推荐把 C2 直接上线：它以拒绝正常建议答案为代价换取缺口拦截，属于用可用性换指标。
