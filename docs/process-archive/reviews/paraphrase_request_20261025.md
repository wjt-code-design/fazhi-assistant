# 改写问法征集（第三方）

## 这份文件要你做什么

请为下面 **9 个主题**各写 **3 种不同的问法**，共 **27 条**。
用途：检验我们的检索系统对「同义问法」是否也有效，不涉及法律判断，不需要给答案。

## 写作要求

1. **每条只写问题本身**，不写答案、不写法条、不做法律分析。
2. 三个版本要有明显差异，按下面三种口吻各写一条：
   - **v1 纯口语**：像普通人在群里问，尽量不用法律术语。
   - **v2 半口语**：可以用一个日常能听到的法律词（如「合同」「处罚」「上诉」）。
   - **v3 正式咨询**：像写给律师/客服的咨询，但**不要照抄原题**。
3. 每条 **10–40 个汉字**，简体中文，一句话。
4. **不要直接复用原问题的措辞**：至少一半实词要换掉，句式也要变。
5. 不要增加会改变法律问题的新事实（金额、亲属关系、是否受伤、是否起诉等）。
6. 同一主题的三条必须指向**同一个法律问题**，不能一条问程序、一条问赔偿。

## 盲写要求（重要）

- 请不要查看本项目的 `backend/query_expansions.json`、`docs/process-archive/plans/retrieval_expansion_20261025.md`
  或任何评测脚本/结果文件。
- 不要猜测「系统想听到哪些词」；按普通用户自然问法写。
- 如果你能看到本仓库，请在写作期间不要打开上述文件。

## 回执格式

请填写同目录下的 `paraphrase_template_20261025.csv`，列名不要改：

| 列 | 必填 | 说明 |
|---|---|---|
| `topic_id` | 是 | 101/103/.../153，不要改 |
| `variant` | 是 | v1 / v2 / v3 |
| `paraphrase` | 是 | 问法正文，10–40 汉字 |
| `notes` | 否 | 如使用了某个法律词，可注明 |

- 27 行全部填满，不得留空。
- 回传文件名：`paraphrase_receipt_20261025.csv`（或同列的 xlsx/markdown 表格）。
- 不要合并多个人的版本；多人请分别回传。
- 截止时间与回传地址：`【由项目方填写】`。

## 收到后会怎么用（预先声明，避免事后改口径）

1. 先做**触发词命中检查**：每个主题的 3 条问法里，至少 **2 条**命中现有触发词，该词条才保留；
   否则该词条淘汰，**不会为了救它临时改 trigger**（防止用同一批问法调参）。
2. 再做检索对比：用这 27 条问法比较「扩展前/扩展后」的 recall@4；
   只合并「命中达标且不产生回归」的词条。
3. 27 条问法只用于本轮验收，不进入回归题库。
4. 不会用这批问法训练模型，也不会对外披露写作者身份。

## 不需要做的事

- 不需要判断法条对错、不需要引用条文、不需要解释理由。
- 不需要考虑「系统能不能搜到」——按真实用户怎么问就怎么写。
