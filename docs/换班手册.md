# 换班操作手册（embedding / rerank 多模型）

> ADR-011 阶段7 · 2026-08-04。面向运维，解释"模型配额耗尽时怎么续"。

## 一、rerank（自动，无需手动）

rerank 走**多模型自动轮换**，无需任何手动操作：

```
qwen3-rerank（~1M）→ 配额 <5% 自动切 → gte-rerank-v2（~1M）→ 自动切 → qwen3-vl-rerank（~1M）
→ 全部耗尽 → 自动降级本地 cosine 精排（仅排序准度降，检索不中断）
```

- 每模型独立配额记账（quota_store key = 模型名），后台各一条进度条
- 换班序列在 `backend/.env` 的 `RERANK_MODELS`（逗号分隔，顺序即优先级）
- 每模型配额在 `RERANK_QUOTA_TOTALS`（逗号分隔，与模型对齐；留空则都用 `RERANK_QUOTA_TOTAL`）

## 二、embedding（换班制，手动）

embedding **不能自动轮换**——不同模型语义空间不同，换模型必须**重建整个向量库**
（~861K token ≈ ¥0.43，几分钟）。这是运维操作，不是运行时自动事件。

### 换班序列（强度降序，先用强的，耗尽再下探）

| 档位 | 模型 |
|---|---|
| 主力 | text-embedding-v4（当前，剩 ~209K） |
| 强 | tongyi-embedding-vision-plus、qwen3-vl-embedding |
| 中 | tongyi-embedding-vision-plus-2026-03-06、qwen3.7-text-embedding、tongyi-embedding-vision-flash-2026-03-06 |
| 弱（轻量） | tongyi-embedding-vision-flash、qwen2.5-vl-embedding |

> 强弱按命名/产品定位推断，实际质量以阿里云文档为准。换班成本恒定（每次重建 861K），
> 所以**每次换班后该模型只剩 ~139K**（1M − 861K）≈ 350 次问答——换班是"用完一次烧一次"。

### 一键换班

```bash
cd C:\Users\33393\Desktop\ai-legal-helper\backend
venv\Scripts\activate
python scripts\switch_embedding.py tongyi-embedding-vision-plus     # 换班（校验配额 → 改 .env → 全量重建）
python scripts\switch_embedding.py <模型名> --dry-run                # 只校验/估费，不真换
```

脚本自动：校验模型在序列 → 检查当前配额够重建 → 改 `EMBEDDING_MODEL`（+ `--dimensions` 改维度）→ 跑 rebuild → 提示重启。

### 手动换班（等价三步）

1. `backend/.env` 改 `EMBEDDING_MODEL=<目标模型>`（维度不同还改 `EMBEDDING_DIMENSIONS`）
2. `python scripts\rebuild_embeddings.py`（全量重嵌入 + count/维度/eval 抽样召回校验）
3. 重启后端

### 终极免费保底（零成本）

即使不换班也有退路：`backend/.env` 设 `EMBEDDING_PROVIDER=local` + 重启 → 直接用回
**本地 BGE + 旧 cos 库**（免费、无限用、只是准度/速度降）。作为 409 之外的零成本保险。

## 三、配额耗尽的行为

| 场景 | 行为 |
|---|---|
| rerank 某模型 <5% | 自动切队列下一个模型（后台标红「已降级」仅当**全部**耗尽） |
| rerank 全部耗尽 | 自动降级本地 cosine 精排，检索不中断 |
| embedding <15% | 后台标黄「建议准备换班」 |
| embedding <5% | 后台标红「接近耗尽，请换班」 |
| embedding 耗尽 | 问答返回 **409**「embedding 配额已耗尽，请换班或切回 local」——不悄悄降级 |

## 四、配额诚实计费（grilling 决策「都算」）

以下消耗**都计入**对应模型配额，后台数字 = 真实剩余：

- 每次问答的检索嵌入（query / 精排 / QA）
- 管理员导入新法条（写库嵌入）
- **换班重建（861K/次）**——换班后该模型配额如实显示剩余（≈139K），不会虚高

## 五、管理员后台

`/api/admin/llm-status` 返回 `utility_quota`：embedding 一条 + 每个 rerank 模型一条，
带 `fallback` 字段驱动前端文案（rerank="local_cosine" 已降级本地精排；embedding="manual_rebuild" 需手动换班）。
