- 冷启动不是「第一题特别慢」：5 题 TTFT 分别为 5374 / 4173 / 5714 / 3513 / 4100ms，

- 因此 DoD 的 3s 冷启动目标不现实：预热只能消掉检索/客户端一次性成本，
  无法降低模型首 token。要压到 3s 内，需要换更快的模型、缩短 prompt 或关闭思考，
  而不是继续加预热。
