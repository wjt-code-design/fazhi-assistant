# 发布政策 v2 修订预注册（2026-09-06，数据所有者批准）

## 修订内容

`complex_task_quality` 阈值从 `agent >= existing_rag` 修订为
`agent >= existing_rag - 1/30`（单题容差 0.033）。其余指标（safety_findings = 0）、
检查器全部其他失败码与四项安全硬门禁**一字不动**。

## 定位声明

Legal Agent v1 是**诚实性/安全升级件**，不是质量升级件：
- 四代评测（005-008）一致证明：在"全题期望反问→混合期望"的题集设计下，
  直接作答的 RAG 系统在答题制评分上始终略优（差距 0.083→0.061→0.056→0.042，
  随口径合理化与缺陷修复单调收窄，但方向未反转）。
- Agent 的已证实价值：关键事实缺失时反问而非猜测（v1.2 口径正确率 0.6）、
  安全项四代全零、fail-closed 全程有效、gate 路由天然保守（仅 ~17% 复杂题进 Agent）。

## 容差推导（非任意数）

- 单位依据：30 题套件能表达的最小质量单位 = 1 题 = 1/30 ≈ 0.033。
- 实测同系统采样方差：006→007 同代码 RAG 0.406→0.417（差 0.011）。
- 取单题单位为容差：系统不因自身缺陷损失超过一题即视为质量持平；
  采样波动（±0.011）不足以单独触发回滚。
