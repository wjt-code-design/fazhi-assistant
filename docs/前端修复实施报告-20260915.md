## 1. 修复项明细

### 1.1 主按钮文字对比度不达标（WCAG 1.49 → 8.71）

**问题**：`.btn-primary` 在樱花粉渐变（`#f6c8d5 → #eba9bd`）上使用白色文字，实测 WCAG 对比度仅 1.49 / 1.92，远低于 AA 要求的 4.5。该样式覆盖发送、登录、创建账号、搜索等全部主要操作按钮。

**修改**（`globals.css:389`）：

```diff
 .btn-primary {
   background: var(--grad);
-  color: #fff;
+  color: var(--ink);
```

**取舍说明**：保留粉渐变、文字改墨蓝 `--ink`（`#23314f`），对比度升至 8.71 / 6.74，品牌视觉不变；备选方案（深粉实底 + 白字，对比度 4.77）会失去渐变层次，未采用。**此项含品牌观感取舍，如验收不满意可一行换回。**

### 1.2 印章 Logo 文字同源问题

**问题**：`.logo-seal` 与主按钮共用同一粉渐变底，白色 `§` 同样只有 1.49 对比度。

**修改**（`globals.css:821`）：`color: #fff` → `color: var(--ink)`，与 1.1 统一处理。

### 1.3 admin 页引用了未定义的按钮样式类

**问题**：`.btn-ghost`（用户列表"启用/禁用"，`admin/page.tsx:523`）与 `.btn-outline`（知识库分页，`:687/:691`）在样式表中从未定义，按钮无框无底，渲染成难以辨识的裸文字。

**修改**（`globals.css:427-445` 新增）：

```css
.btn-ghost {
  background-color: transparent;
  color: var(--slate);
  border: 1px solid transparent;
}
.btn-ghost:hover:not(:disabled) {
  background-color: var(--mist);
  color: var(--ink);
}
.btn-outline {
  background-color: transparent;
  color: var(--ink);
  border: 1px solid var(--mist);
}
.btn-outline:hover:not(:disabled) {
  background-color: var(--mist);
}
```

**设计依据**：对齐同文件既有 `.btn-secondary` 的浅色后台语境（透明底 + mist 边框/悬停），未引入新色值。

**遗留建议**："禁用他人账号"按钮当前为 ghost 样式（已可辨识），若希望强化操作风险感，可改挂 `btn-danger` 红色系；涉及观感取舍，本次未定。

### 1.4 反馈状态跨会话错配（状态 bug）

**问题**：`fbDone`（👍/👎 已反馈标记）与 `corrFor`/`corrText`（纠错输入态）以**消息数组下标**为 key（`chat/page.tsx:884`），但 `newChat` / `selectConv` / `deleteConv` 三处切换会话时重置了其它全部状态、唯独漏了这三个。

**复现路径**：会话 A 第 3 条消息点 👍 → 切到会话 B → B 的第 3 条消息（内容完全不同）错误显示「已记录，谢谢反馈」且按钮被禁用。

**修改**：三个入口统一补三行（`chat/page.tsx:435-437 / 450-452 / 483-485`）：

```ts
setFbDone({});
setCorrFor(null);
setCorrText("");
```

**修法选择**：采用切会话即清空的止血方案。根治需改为按消息唯一 id 索引，依赖后端为历史消息暴露稳定 id（当前接口无此字段，已核实 `api.ts:92` 的 `HistoryMsg` 类型），属契约变更，超出本次范围。

### 1.5 参考条文数据收了不渲染（功能缺失）

**问题**：后端 SSE meta 帧每次都下发 `sources`（已核实 `backend/main.py:1568` 等 7 处 `yield`），前端也写入了消息 state（`chat/page.tsx:675`），但渲染侧全仓 0 处使用。对法律问答产品而言，"结论依据哪一法条"是可核对性的核心：数据链路已通，只差最后展示。

**修改**（`chat/page.tsx:1234-1248` 新增）：在 AI 气泡下方、👍/👎 行之前插入折叠区：

```tsx
{!streaming && m.role === "assistant" && m.sources && m.sources.length > 0 && (
  <details className="mt-2 rounded-lg border border-mist bg-white/50 px-3 py-1.5">
    <summary className="cursor-pointer select-none text-xs text-slate hover:text-ink">
      参考条文（{m.sources.length}）
    </summary>
    <ul className="mt-1.5 flex flex-wrap gap-1.5 pb-1">
      {m.sources.map((s, si) => (
        <li key={si} className="rounded-full border border-sea/40 bg-sea/5 px-2.5 py-0.5 text-xs text-ink">
          《{s.source}》{s.article}
        </li>
      ))}
    </ul>
  </details>
)}
```

**行为**：流式期间不显示（避免中途闪烁），回答完成后出现「参考条文（N）」折叠条，展开为《法名》第X条 药丸标签。`<details>/<summary>` 原生实现，零新增依赖、键盘可达。

**已知边界（重要）**：后端消息表（`backend/models.py` `Message`）无 sources 持久化列，`selectConv` 恢复历史时该字段必然为空。即：**参考条文只在当前会话的回答里可见，切回历史会话不显示**。如需持久化，须后端加列并改写入/读取链路，属后续工作。
