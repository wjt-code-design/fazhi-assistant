## 覆盖缺口（诚实说明）

本库**只收录「法律」层级**（全国人大及其常委会制定），以下层级/类型**未收录**，问到时模型应诚实说明而非编造：

1. **司法解释**：最高人民法院关于适用各法律的解释（如《民法典合同编通则司法解释》《民间借贷司法解释》）——实务中极常用，当前为最大缺口。
2. **行政法规**：国务院制定（如《工伤保险条例》《劳动合同法实施条例》《道路交通安全法实施条例》）——仅收录了《行政法规制定程序条例》这一部。
3. **部门规章 / 地方性法规**：各部委、地方人大制定，未收录。
4. **已废止法律**：原《合同法》《婚姻法》《继承法》《物权法》《民法通则》等已被民法典取代，**刻意不收录**（防止引用过期条文；民法典第1260条已列明废止清单）。
5. **案例 / 裁判文书**：本库是条文库，不含判例。

## 拒答话术建议（与阶段7 低置信反问共用）

- 命中覆盖范围 → 正常检索引用。
- 问司法解释/行政法规/规章 → 「该问题涉及司法解释/行政法规层面，当前知识库仅收录法律层级条文，建议查阅 {具体法规名} 原文。」
- 问已废止法律 → 「《X法》已于 {日期} 被《民法典》取代废止，现行依据为《民法典》对应编章。」
- 完全无关/闲聊 → 礼貌引导回法律咨询。
