## 问题

隐藏验收集（H01–H05）设计声明覆盖 5 个元素，但两次正式运行（run-a/b）中：

| 要素 | 运行层触达 |
|---|---|
| F1 用户更正前一事实 | **0 次**（关键词表与 Agent 追问方向错位，更正 fact 从未投放/提前投放变形） |
| F2 两轮后仍无唯一结论 → 条件化 | 部分（H02 有条件化语义） |
| F3 知识库证据不足 → 缺口说明 | 部分（H03 缺口题，但 final 为空无输出） |
| F4 相似事实不同结论（防记忆迁移） | 部分（集内设计存在，运行无正样本证明） |
| F5 提示注入 / 越权诱导 | **0 次**（注入文本未命中关键词而从未投放） |

根因：投放协议为先验关键词匹配（KEYWORDS 表），与 Agent 实际追问的**语义方向**系统性错位——Agent 问"是否出具书面解除通知"，协议词表里没有"解除通知"即不投放，回答固定话术。

## 影响评估

1. **本轮判定结论不变**：0/5 + 0/5 的判定依据是技术失败、六段式缺失、required_laws 零命中——不依赖 F1/F5 是否触达。因此缺口**不影响本轮验收结论**。
2. **证明力缺口**：若未来声称"隐藏集覆盖 5 要素已验证 Agent 抗注入/更正能力"，当前运行层证据不成立。F1/F5 的安全性验证责任需明确归属。

## 处置选项

**选项 1：修订投放协议为语义匹配（需 Owner 解冻协议）**
- 做法：把 KEYWORDS 关键词精确命中改为向量/语义匹配（与 Agent 追问方向对齐），或对每 fact 补全同义词表（如"解除通知书→辞退通知→解雇文件"）。
- 成本：低（表/脚本改动）；可保留题集与承诺，重跑一轮 F1/F5 专项验证。
- 风险：语义匹配可能过度投放（把"条件化推进"变成"提前给事实"），需要严格"问到才答"纪律回归测试。

**选项 2：重建隐藏集（新题+新承诺，最彻底）**
- 做法：设计新隐藏题（F1/F5 要素内嵌在问答链必经路径），重新冻结+承诺+两轮运行。
- 成本：中高（新题设计、承诺、运行、审核全流程）；且本轮 0/5 未达验收线，重建集的验收意义要在"Agent 质量已达验收线"背景下才有价值。

**选项 3：接受现状，V1 声明收缩**
- 做法：隐藏集结论写明"本轮覆盖 F2/F3/F4（部分）；F1/F5 验证延后至 V1 补测或 V2"；把 F1/F5 作为 V1 后续专项或 V2 必测项。
- 成本：零；诚实但把安全验证推后。
