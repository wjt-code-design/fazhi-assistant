## A 组 · 可立即并行派发（只读或写集隔离）

### T1 · 定位「全量 lane 的 flaky 簇」（**优先级最高**）

**为什么独立**：它不碰产品代码，却**污染所有人的变异审计**。同一命令多次跑给出
**0 红 / 3 红 / 8 红**，红的是同一批用例。本会话三次独立读数：
`dispatch-output/hij-h-20260920/mut-r2/baseline/full-baseline.xml`（0 红）、
`dispatch-output/hij-h-20260920/mut-r2b/baseline/full-baseline.xml`（8 红）、
`dispatch-output/hij-j-20260920/mut/baseline/full-baseline.xml`（8 红，同集合）。

**输入**：上面三份 junit（判据逻辑复用 `dispatch-output/s5-followup-20260920/run_mutations_full.py`
的 `failed_set` / `suite_stats`，别另写一份解析）。
**判据（我要复核的）**：
1. 同一命令重复 **≥5 次**（每次**唯一 basetemp**），产出「用例 × 跑次」红/绿矩阵；
2. 每条 flaky 给**最小复现**（哪几个条件同时成立才红）与**根因**（不接受"可能跟负载有关"）；
3. 归类到「顺序依赖 / 共享状态 / 时间敏感 / 外部依赖」，**逐条给证据**。
**我不接受**：≥5 次里 0 次复现的"疑似 flaky"；只跑一次就下结论。
**边界**：**只诊断、不改**。要修先报根因与方案等 Owner 点。写集 = `dispatch-output/t1-flaky-<日期>/`。

### T2 · `-m slow` 那 18 条到底跑不跑得通

**为什么独立**：本轮所有门禁读数都是 `-m "not slow"`；18 条 slow 至今没有本轮读数。
（已核对：`pytest -m slow --collect-only` = `18/1408 collected`。）
**输入**：需要**已填充 KB** 的树（票面说 slow 需要真实知识库）。
**判据**：`passed/failed/deselected` 逐项 + 与 `-m "not slow"` 的**分母对账**（1408 = 1390 + 18）；
若有红，逐条给红因原文并判断是"环境缺 KB"还是"真回归"。
**我不接受**：把"环境缺 KB 的 skip/error"报成回归，或反之。
**边界**：只读 + 报告；不得为了跑通去改 `.env`。写集 = `dispatch-output/t2-slow-<日期>/`。

## 验收：我复核什么（不看你说了什么，只看读数）

| 任务 | 我重跑的命令 | 通过条件 |
|---|---|---|
| T1 | 你给的那条重复命令，我自己再来 ≥3 次 | 红/绿矩阵与你的**逐格一致**；每条 flaky 有最小复现与根因；0 次复现的名字不算 |
| T2 | `pytest -m slow`（有 KB 的树） | 分母与 `-m "not slow"` 对账得上；红因原文可复核；未改 `.env` |
| T3 | 你给的只读命令 | 读数与我独立读到的宿主 `app.db` `cc=10710 / size 19939328 / mtime 2026-09-17 02:37` 一致 |
| T4 | `git status --porcelain` 计数 | 360 项能对上；"可清理"清单里**没有**被实际删掉的东西 |
| T5（票 I） | 按票面 §9 逐条 | 回表 `grep -c '"GAP-TODO"'` 与声明一致；变异分母与基线**相等**；先红红因原文非 TypeError；我另造变异能杀你的新断言 |

**我会打回的形状**（本轮真出现过，逐条点名）：
① **空枪断言**——例：`assert sink == []` 因为压根没有 `cache_key` ⇒ 恒真（必须配同形状控制腿）；
② **红因是 `AttributeError`/`TypeError`**——例：引用一个改前树不存在的常量（改成显式断言）；
③ **"跑完了"但没有产物**——例：执行器 `ModuleNotFoundError` 或忘 `mkdir -p` 输出目录 ⇒
整轮瞬间全灭、stdout 只有 traceback。**每个跑次必须回读产物**（junit / verdict.json），
不能只看进程退出码；
④ **定向绿当全量绿**——实测：定向 7 passed，全量 lane 里同一批用例因**模块级 `answer_cache`
被别的测试文件写入**而 3 条红。涉及共享状态的判据必须给"与邻居同跑"的复现命令。
