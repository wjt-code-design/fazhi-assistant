## 3. 过程中的两次自我纠错（都是**我的假设错**，不是页面缺陷）

1. **"登录页应有表单"** ⇒ 实际是**封面 → 钤印入典 → 表单**两步交互：首轮 DOM 取证实测 `input=0 / button=1(§钤印入典)`。
2. **"点『登录』按钮提交"** ⇒ 页面有**两个同名按钮**：tab 是 `type=button` 文本「登录」，提交是 `type=submit` 文本「**登 录**」（中间有空格）⇒ `has-text("登录")` 只匹配到 **tab**，点击落空（**零请求零报错**，等待撞上我自己设的 20 次上限）。改用 `button[type="submit"]` 后一次通过。
